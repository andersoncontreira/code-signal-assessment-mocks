# CodeSignal Industry Coding Assessment — Mock Prep

Preparation for the Airbnb **Industry Coding Assessment** (CodeSignal), Senior Fullstack Software Engineer, Quality Platform.

## Test format

- One project-style question with **4 progressive levels**. Each level extends the previous one, and the next level unlocks only after the current one passes its tests.
- 90 minutes, single session, browser editor, proctored (webcam, microphone, ID document).
- No AI, extensions or external tools during the test.
- Deadline: **2026-11-05, 23:29 (Brasília time)**.

## Workflow per mock

1. Start a 90-minute timer.
2. Implement level by level. Do not rewrite previous levels, extend them.
3. When time is up, save the code and note: levels reached, time spent per level, where you got stuck.
4. Review: lost time, missed edge cases, how to structure code so the next level plugs in easily.
5. Re-do the weak spots before moving to the next mock.

## Language

Pick one language and stay with it. Python is recommended for speed; TypeScript is fine if classes and types are second nature.
